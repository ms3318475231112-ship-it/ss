# ترصيد الحسابات – برنامج للموبايل

تطبيق لتسجيل الوارد والصادر (نقدي وانستا) مع كشف حساب وتصدير PDF وExcel ونسخ احتياطي JSON.
الفولدر ده فيه طريقتين لتشغيله على الموبايل من GitHub، اختار واحدة (أو الاتنين).

أولًا ارفع **كل محتويات الفولدر** على Repository جديد في GitHub، مع مجلد `.github` المخفي.
بعد رفع الملفات هيشتغل البناء تلقائيًا من تبويب **Actions**.

## الطريقة 1: تثبيت من رابط GitHub Pages (الأسهل، أندرويد وآيفون)

1. في الـ Repository: **Settings ← Pages ← Source** اختار **GitHub Actions**.
2. افتح **Actions** وشغّل «Deploy to GitHub Pages» بزر **Run workflow** (أو ادفع أي تعديل).
3. بعد ما ينجح هتلاقي الرابط في نفس الصفحة، شكله `https://اسم-المستخدم.github.io/اسم-الريبو/`.
4. افتح الرابط من الموبايل:
   - أندرويد (Chrome): قائمة ⋮ ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
   - آيفون (Safari): زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

بعد التثبيت بيفتح بالأيقونة وبشكل ملء الشاشة وبيشتغل من غير إنترنت.

## الطريقة 2: ملف APK لأندرويد

1. افتح **Actions** وشغّل «Build Android APK» (بيشتغل تلقائيًا بعد الرفع كمان).
2. بعد حوالي 5–10 دقايق نزّل **tarsid-accounts-apk** من قسم Artifacts، فك الضغط وهتلاقي `app-debug.apk`.
3. انقل الـ APK للموبايل وثبّته (فعّل «التثبيت من مصادر غير معروفة» لو طلب).

## هيكل الملفات

- `www/index.html`: الواجهة كلها (الكود الأساسي للتطبيق).
- `www/manifest.webmanifest` و`www/sw.js` و`www/icons/`: ملفات التثبيت من المتصفح والأيقونات.
- `assets/`: الأيقونة الأصلية (`icon-only.png` و`icon-foreground.png` و`icon-background.png`). منها بتتولد أيقونات أندرويد تلقائيًا.
- `assets-src/`: مصادر SVG للأيقونة.
- `capacitor.config.json`: اسم التطبيق (`appName`) والمعرّف (`appId`) للـ APK.
- `.github/workflows/`: `pages.yml` للنشر على Pages، و`build-apk.yml` لبناء الـ APK.

## ملاحظات

- البيانات محفوظة على الموبايل نفسه (IndexedDB). لو مسحت بيانات المتصفح أو حذفت التطبيق هتضيع، فخد نسخة JSON من صفحة «تصدير ونسخ» بشكل دوري.
- بيانات نسخة Pages ونسخة الـ APK منفصلة عن بعض، فاستخدم واحدة بس، أو انقل البيانات بنسخة JSON.
- التصدير (PDF / Excel / JSON) في الـ APK بيفتح قائمة المشاركة في أندرويد عشان تحفظ الملف أو تبعته. وفي نسخة Pages بيتحمّل مباشرة.
- نسخة الـ APK Debug للاستخدام الشخصي. للنشر على Google Play محتاج توقيع Release.
- لتغيير الاسم أو المعرّف عدّل `capacitor.config.json` قبل أول بناء.
